## 🛠️ Technologies Used

- **Language:** Python
- **Editor:** Visual Studio Code
- **Version Control:** Git and GitHub

## ▶️ How to Run the Programs

1. Install Python 3.12 or later.
2. Clone this repository:

   ```bash
   git clone https://github.com/daredevil0005/Python_Assignments.git
   ```

3. Navigate to the assignment folder:

   ```bash
   cd Python_Assignments/conditional_assignments
   ```

4. Run any program:

   ```bash
   python Question-01.py
   ```

   Replace `Question-01.py` with the filename you want to execute.
